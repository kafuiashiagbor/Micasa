# Micasa Real Estate Management System

A Visual Basic desktop application designed to help real estate companies manage properties, clients, sales, and rental operations efficiently.

## 🖥️ Overview
Micasa is a Windows-based management system that provides a centralized dashboard for tracking real estate activities. It allows agents and administrators to monitor property listings, manage clients, and track financial performance.

## ✨ Features

- 🏠 Property Management  
  Add, update, and manage available properties  

- 👥 Client Management  
  Store and manage client records  

- 💰 Sales Tracking  
  Record and monitor property sales  

- 📅 Rental Management  
  Track rented properties and rental activity  

- 📊 Dashboard Analytics  
  View key statistics such as:
  - Total properties managed
  - Properties sold and rented
  - Available listings
  - Total rent received
  - Overdue rent
  - Commission tracking  

- 📈 Reports  
  Generate sales reports for performance insights  

- 💳 Rent Payments  
  Track and manage rental payments
